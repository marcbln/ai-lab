# ai-lab

A monorepo for prompt-driven AI experiments. Games, 3D demos, websites, themes — everything here is generated by LLMs from evolving prompts, then iterated on until it feels polished.

The point is to gamble with LLMs and see what comes out. Prototypes are welcome; perfection is not required.

## What lives here

| Path | Description |
| --- | --- |
| `ds-v4-flash/` | First project: "City Defender 3D" — a Three.js arcade game |
| `prompt.md` | Root prompt(s) used to bootstrap the first project |
| `_ai/` | AI knowledge base — lessons learned, backlog, technical decisions |

## How it works

Each project is a self-contained folder with its own `_ai/` directory for prompts, lessons learned, and decisions. Projects cross-pollinate: an AI model working on a new project can learn from the prompts and lessons of every other project in the repo.

The root `_ai/` holds the same kind of knowledge base at monorepo level, so patterns that prove themselves get promoted and reused.

## Run the projects

Every project is self-contained (no build step required to just view it). Serve the folder over HTTP and open the page:

```sh
# from the project folder, e.g. ds-v4-flash/
python3 -m http.server 8080
# then open http://localhost:8080 in a browser
```
